# 2026年程序员必备效率工具推荐

> 工欲善其事，必先利其器。这些工具我每天都在用。

---

## 1. 开发工具

### VS Code — 编辑器之王

- **插件推荐**：
  - `C/C++ Extension Pack`：C++ 开发必备
  - `GitHub Copilot`：AI 辅助编程，效率翻倍
  - `Rainbow Brackets`：彩虹括号，一眼看清嵌套
  - `Code Runner`：一键运行代码片段
  - `Markdown All in One`：Markdown 写作增强

### CLion — C++ 专业 IDE

如果 VS Code 满足不了你，CLion 是 JetBrains 家族里最值得买的 IDE。代码分析、重构、调试一体化。

### Neovim — 终端编辑器

配置好 LSP 和 Telescope 之后，Neovim 完全不输 IDE。适合喜欢键盘操作的同学。

---

## 2. 终端工具

### Windows Terminal + oh-my-posh

Windows 上最好的终端。配合 oh-my-posh 主题，git 分支、退出码一目了然。

```powershell
# 安装 oh-my-posh
winget install JanDeDobbeleer.OhMyPosh -s winget

# 安装 Nerd Font（推荐 CaskaydiaCove NF）
winget install CJKispeziali.CaskaydiaCoveNF
```

### WSL2

Windows 上跑 Linux 环境必备。文件系统互通，Docker 也跑在 WSL2 上。

### zoxide — 智能 cd

比 `cd` 更聪明的目录跳转，学习你的习惯后可以直接 `z 项目名` 跳转。

```bash
# 安装
cargo install zoxide

# 使用（替代 cd）
z project
z blog
```

### lsd + bat — 更漂亮的 ls 和 cat

- `lsd`：带图标和颜色的 ls
- `bat`：带语法高亮的 cat

---

## 3. Git 工具

### Lazygit — 终端 Git GUI

不用再记那一堆 git 命令了。在终端里用 TUI 界面操作 git，分 stage、commit、rebase 一目了然。

```bash
# 安装（winget）
winget install JesseDuffield.lazygit

# 使用
lazygit
```

### gitmemo

记录你每个 git 仓库做了什么，适合需要写周报的同学。

### Oh My Git! — 游戏学 Git

想搞懂 git 的底层原理？玩这个游戏就够了：[Oh My Git!](https://ohmygit.org/)

---

## 4. 笔记与知识管理

### Obsidian

本地 Markdown 笔记，双链笔记的鼻祖。配合插件可以实现：
- 看板（Kanban）
- 日记模板
- 代码块高亮
- 导出 PDF/HTML

### Logseq

大纲笔记 + 日程管理一体。适合做 journaling 和知识图谱。

### Notion

All-in-one 工作空间。适合团队协作、项目管理、数据库。

---

## 5. 系统工具

### DBeaver — 数据库管理

支持 MySQL、PostgreSQL、SQLite 等几乎所有数据库。免费开源，界面美观。

### Postman / Bruno — API 测试

Postman 太臃肿？试试 **Bruno**，开源、离线、速度快。

### Flow Launcher / Wox — Windows 启动器

类似 macOS 的 Spotlight。快速打开文件、运行程序、搜索网页。

```powershell
# 安装 Flow Launcher
winget install Flow-Launcher.Flow-Launcher
```

### Sysinternals Suite

微软官方出品的系统工具集，包含：
- Process Explorer：加强版任务管理器
- Autoruns：开机启动项管理
- TCPView：网络连接查看

---

## 6. Docker 相关

### Docker Desktop

WSL2 后端，性能比 Hyper-V 好很多。

### Portainer

Docker 的 Web 管理界面，可视化管理容器。

### lazydocker

终端里的 Docker 管理工具，比 `docker ps` 好用。

---

## 7. 浏览器工具

### uBlock Origin

最好的广告拦截器。别用 AdBlock， donation 太多。

### Tampermonkey

用户脚本管理器。配合脚本可以实现：
- 百度网盘直链下载
- 视频网站去广告
- 网页全文复制

### Bitwarden

开源密码管理器。免费版就够用，跨平台同步。

---

## 总结

上面这些工具按需选用，不用全部安装。我的核心组合：

- **编辑器**：VS Code + Neovim
- **终端**：Windows Terminal + oh-my-posh
- **Git**：Lazygit
- **笔记**：Obsidian
- **数据库**：DBeaver
- **启动器**：Flow Launcher

工具只是手段，关键是**用工具提升效率，而不是折腾工具本身**。🛠️
