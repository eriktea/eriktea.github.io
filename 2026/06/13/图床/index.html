Github+PicGo搭建图床

Github+PicGo搭建博客

图床，顾名思义，是专门用于存放图片的仓库。在这里，我推荐一种免费且高效的方案：利用 GitHub 的仓库机制作为存储空间，配合 PicGo 工具将图片批量上传。这样，你就拥有了一个属于自己的免费图床。

PS：受 GitHub 仓库限制，虽然免费但要注意单仓库容量管理。

Github方面


一、首先注册 GitHub 账号

Github地址： https://github.com/

你可以参考GitHub 官方注册教程来完成账号创建，这里不多赘述。

二、创建放置图片的仓库

  1. 点击页面右上角的 + 号图标,然后下拉菜单中选择 **”New repository”**（如下图所示）：
  2. 进入创建页面后，填写仓库名称（例如 my-images）我这边随手写了个pixiv_picgoc，并将仓库设置为 Public（公开），最后点击底部的 **”Create repository”**（如下图所示）：
  3. 此时点击头像->Settings->Developer settings（如找不到请下滑到最底下），进入后点击Tokens(classic)
  4. 在右下角中点击Generate new token，切换成Generate new token(classic)并点击进去
  5. 填写note(也就是key的别称，可以随意填写);将Expiration下换成No Expiration，随后一定一定要勾选上repo;做完这些后下滑点击Generate token即可获得到仓库的专属Token，一定要第一时间保存，页面刷新后就会丢失

PicGo方面


三、下载PicGO

  1. PicGO是一个开源的图片上传工具,这是开源软件，请务必从官方仓库下载，不要在第三方下载站下载，以免带入木马,官方仓库:PicGo在github的网站

  1. 打开网站后,找到版本v2.5.2,按照自己PC的配置来选即可


  2. 安装过程非常简单，只需要一路Next即可，这里不进行教学


四、 配置PicGo

  1. 完成安装后，打开PicGo，会发现此时是英文界面，找到Plugins Settings,找到Choose Language即可将PicGo切换成汉语言界面


  2. 在切换汉语言界面后，点击图床设置，找到GitHub 点击 + 即可进行Github的配置，其中图床配置名可以自定义;设定仓库名一定要按照格式，格式为’github用户名/仓库名’；分支名直接填’main’即可；设定Token，这里的Token就是该仓库的key，就是前文申请的那个，直接填在这一栏即可；设定存储路径这一栏可以留空，留空默认会将图片放在根目录，也可以填写images/，如此填写的话就会在根目录创建images文件夹，并将图片放置在images文件夹内
    为了方便理解，在此放上填写示例：


  3. 在布置好所有配置之后，就可以切回上传区，此时会看到有几个转换格式，如markdown和URL，写博客配置时，如壁纸配置，选择URL；写博客文章需要插入图片时，选markdown即可，它会自动为你生成链接并自动复制，将链接直接粘贴到博客里就能显示图片，同时这些图片也都上传到了Github的仓库内
