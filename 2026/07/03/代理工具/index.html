PC端和Mobile端的代理工具配置

前言
PC端：Clash Verge Rev 是目前 Windows 和 macOS 平台上最流行、界面最好看的 Clash 内核代理客户端之一。它不仅完美适配了最新的 Mihomo 内核，还以极其简约直观的 UI 设计赢得了众多用户的青睐。

Mobile端：NekoBox 是目前 Android 平台上最流行、功能最完善的 Sing-box 内核代理客户端之一。它支持订阅导入、TUN 模式、规则分流以及多种代理协议，同时拥有简洁易用的界面设计，能够满足绝大多数用户的日常使用需求。

PC 端的 Clash Verge Rev 主要通过“系统代理”接管应用流量；Android 端的 NekoBox 则通常通过系统 VPN / TUN 模式接管流量，两者的实现方式不同，但使用目标是一致的,这里暂不进行区别表述

本文将详细教学这两款代理工具的安装、配置以及订阅导入方法。

使用前准备

在开始配置之前，建议先明确下面几个概念：

  1. 客户端不提供节点，机场才提供节点

像 Clash Verge Rev、NekoBox 这类软件，本质上只是代理客户端，负责导入配置、切换节点和接管网络流量；真正提供节点的是机场服务商。

也就是说，如果你没有机场提供的订阅链接，单独安装客户端是无法直接使用代理的。

  1. 订阅链接是什么

订阅链接通常是一段由机场提供的 URL，用于让客户端自动拉取：

节点列表
分流规则
DNS / 路由配置
策略组配置

导入订阅后，客户端才会显示可用节点与规则。

  1. 规则模式和全局模式的区别

常见的代理模式一般有两种：

规则模式：按照订阅配置中的规则进行分流。通常表现为国内网站直连、国外网站走代理，但最终仍以订阅本身的规则配置为准。
全局模式：所有流量统一走代理，不再区分国内外网站。

日常使用一般优先推荐 规则模式；只有在某些应用地区限制较严格、或者规则命中异常时，才临时切换为 全局模式 测试。

PC端配置（Clash Verge Rev）


📥 客户端下载

  • Clash Verge Rev: 前往 GitHub 官方下载页面

点击下方对应版本，即可跳转至下载页面：

Windows 系统

  • 64位常用版本 (exe/msi)

macOS 系统

  • M芯片版本 (dmg)
  • Intel芯片版本 (dmg)

🔗 导入订阅

  1. 打开已经安装好的 Clash Verge Rev 客户端
  2. 在客户端界面左侧的导航菜单中,点击进入 Settings 页面，将’Language’从’English’切换成’中文’或’繁体中文’
  3. 在客户端界面左侧的导航菜单中，点击进入 订阅 页面
  4. 在界面顶部的输入框’订阅文件链接’中，粘贴机场的订阅链接，如果尚未有机场链接，可以看另一篇文章’自用机场推荐’
  5. 点击输入框右侧的’导入’按钮
  6. 导入成功后，即可在列表中看到刚刚添加的配置项目
  7. 在列表中右键点击该文件，选择’更新’，如果会刷新，则代表配置可以被正常使用

💡 小提示：请务必妥善保管机场链接，切勿随意泄露给他人。一旦订阅链接泄露，其他人将能够通过该链接使用您的流量配额。

🚀 开启代理

  1. 在左侧导航栏点击进入’代理’页面
  2. 在顶部的代理模式选项中，建议选择’规则’模式（这会让国内网站直连，国外网站走代理）
  3. 在左侧导航栏点击进入’代理’，选择一个延迟较低，状态较好的节点进行使用’如香港、日本、新加坡、马来西亚’
  4. 在左侧导航栏的’设置’页面，找到’系统代理’,将其打开即可
  5. 在完成上述所有配置步骤后，你可以点击此处 测试代理连接是否正常 以确认网络环境是否已成功接入,如果顺利的话，将会进入’维基百科的首页’，这样就代表着可以畅通无阻的访问国际互联网了

🛠️ 常见问题


Q1：开启代理后，国内网站无法访问或速度很慢

可能原因：

误切换成了 全局模式
当前订阅的规则配置不合理
所选节点本身质量较差

处理方法：

进入 代理 页面，确认当前是否为 规则模式
更换其他节点测试
更新订阅后重新尝试

Q2：软件提示“订阅更新失败”或“连接超时”

可能原因：

当前网络本身无法访问机场订阅地址
订阅链接填写错误或已失效
客户端版本过旧，无法解析新配置

处理方法：

检查订阅链接是否完整、是否复制错误
更换网络环境后重试，例如切换手机热点
更新 Clash Verge Rev 到最新版本后再次尝试

Q3：已经开启系统代理，但浏览器或软件依然不走代理

可能原因：

有其他代理工具、VPN 或安全软件冲突
某些应用本身不完全遵循系统代理
系统代理状态异常

处理方法：

关闭其他同类代理工具或 VPN 软件
在 Clash Verge Rev 中尝试重置系统代理
重启客户端后重新测试
如果问题仍存在，可考虑开启 TUN 模式

Q4：TikTok、Copilot、OpenAI 等服务依然提示地区不可用

可能原因：

当前规则没有正确命中对应流量
所选节点地区不匹配或 IP 纯净度不足
浏览器缓存 / Cookie 残留导致地区判断异常

处理方法：

检查相关服务对应的策略组是否已经走代理
如果不确定规则是否命中，可以临时切换到 全局模式 测试
更换其他地区节点，优先尝试质量更高、纯净度更好的节点
清理浏览器缓存、Cookie，或使用无痕模式重新测试

Q5：导入订阅时提示配置解析失败

可能原因：

客户端版本或内核版本过旧
机场订阅格式更新，旧版本不兼容
订阅内容本身异常

处理方法：

优先更新 Clash Verge Rev 到最新版本
重新导入订阅
若仍无法解决，再联系机场客服确认订阅本身是否可用

Mobile端配置（NekoBox）


📥 客户端下载

  • NekoBox: GitHub 仓库

进入仓库往下滑即可看到 ‘NekoBox-1.x.x-arm64.v8a.apk’ ,下载完直接安装即可

🔗 导入订阅

  1. 打开已经安装完成的Nekobox,点击左上角的按钮，在滑出的窗口中点击分组
  2. 在弹出的分组主界面，点击右上角的 ➕ 号按钮即可出现分组设置界面，分组名自定义即可
  3. 随后将分组类型修改成订阅,即可看到下面增加了一个’订阅链接’,将机场的URL链接复制粘贴进这里，随后点击右上角的 √ 保存
  4. 保存后会回到分组页面，可以看到新添加的订阅分组，点击更新

🚀 开启VPN

  1. 在主界面选择一个节点后，点击底部连接按钮启动代理；首次连接时，Android 会弹出“是否允许 NekoBox 创建 VPN 连接”的系统提示，点击允许即可
  2. 以上步骤全部完成后即可使用NekoBox正常的进行全球互联网访问了

🧭 路由设置建议

在 NekoBox 左上角菜单中进入 路由 页面后，可以看到一系列开关和规则项。
这里不建议简单理解为“全部打开”，更合理的做法是按用途分别配置。

下面是比较常见的几个选项说明：

  1. 屏蔽 QUIC

建议：可优先开启

QUIC 是基于 UDP 的网络协议，部分网站或应用（例如 YouTube、Google 系服务）可能会优先走 QUIC。
在某些网络环境下，QUIC 可能导致分流异常、绕过代理或速度不稳定。

如果你遇到以下情况，可以尝试开启 屏蔽 QUIC：

YouTube 加载异常
某些 Google 服务代理效果不稳定
明明开了代理，但部分流量表现不正常

  1. 屏蔽广告

建议：开启

该选项会拦截一部分常见广告域名，减少广告请求。
虽然不能替代专业的广告拦截工具，但日常使用中通常是有帮助的。

  1. 屏蔽跟踪器

建议：开启

该选项主要用于拦截常见统计、埋点和跟踪域名，对减少后台追踪请求和提升隐私有一定帮助。

  1. 中国域名规则

建议：保持默认绕过（直连）

它的作用是：当访问被识别为中国大陆域名的网站时，默认不走代理，而是直接连接。

例如：

国内新闻站
国内视频网站
国内常见服务网站

对于日常使用来说，通常建议保留为 绕过，这样国内网站速度更稳定，也不会浪费代理流量。

  1. 中国 IP 规则

建议：保持默认绕过（直连）

这个规则和“中国域名规则”类似，不过它针对的是中国大陆 IP 地址。
一般情况下也建议保持为 绕过，让国内 IP 流量直接连接。

  1. 中国 Play 商店规则

建议：按需开启

这个选项主要用于控制 Google Play 商店 的流量是否通过代理。
如果你希望 Play 商店始终走代理，可以开启相关规则；如果没有特殊需求，保持默认即可。

🛠️ 常见问题


Q1：NekoBox 已经连接成功，但部分网站还是打不开

可能原因：

当前节点不可用或质量较差
路由规则命中异常
某些流量没有按预期走代理

处理方法：

更换其他节点测试
检查“路由”页面中中国域名 / 中国 IP 规则是否被改乱
视情况尝试开启 屏蔽 QUIC
更新订阅后重新连接

Q2：点击连接后一直无法建立 VPN

可能原因：

Android 系统没有授予 VPN 权限
手机系统限制了后台运行
当前节点或订阅本身异常

处理方法：

确认系统是否已经允许 NekoBox 创建 VPN
检查手机是否限制了 NekoBox 的后台运行、电池优化或联网权限
更换节点后重新连接
重启 NekoBox 或手机后再次尝试

Q3：更新订阅时报错

可能原因：

订阅链接失效或填写错误
当前网络无法访问订阅地址
NekoBox 版本过旧

处理方法：

检查订阅链接是否填写正确
切换网络环境重新更新
更新 NekoBox 到较新的版本
若仍失败，再联系机场确认订阅状态

Q4：国内网站也走代理，导致访问变慢

可能原因：

中国域名规则 / 中国 IP 规则被改成了代理
当前路由配置不合理

处理方法：

回到 路由 页面
检查 中国域名规则 与 中国 IP 规则
一般建议将它们保持为 绕过（直连）
